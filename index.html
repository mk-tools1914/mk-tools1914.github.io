コードバックアップGAS

Google Apps Script 製の個人用バックアップツール

概要

管理者自身が作成・管理している Google Apps Script プロジェクトのソースコードを、 定期的にテキストファイルとして管理者の Google ドライブに保存するツールです。 コードの変更履歴の保管や、内容の確認を目的としています。

主な機能

  • 指定した Apps Script プロジェクトのソースコードを Apps Script API で取得
  • 取得したコードを1つのテキストファイルにまとめ、指定した Google ドライブのフォルダに保存（上書き）
  • 時間主導型トリガーによる自動実行

利用者

本ツールは管理者本人のみが利用するもので、一般への提供や利用者の募集は行っていません。

プライバシーポリシー

Google アカウントのデータの取り扱いについては、 プライバシーポリシーをご覧ください。
